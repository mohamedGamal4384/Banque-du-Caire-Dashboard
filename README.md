# Banque du Caire | Banking Analytics Dashboard

**An End-to-End Business Intelligence Project Using Power BI**

## Project Overview

This project presents an interactive banking analytics dashboard developed using Microsoft Power BI, with the goal of transforming raw sample data into meaningful business insights.

The dashboard explores different aspects of banking operations, including customer behavior, transaction activities, loan performance, and branch operations.

The project focuses on data analysis, business intelligence, and data storytelling to support better understanding of banking performance and operational trends.

## Project Objectives

- Analyze customer profiles and account distribution.
- Understand transaction patterns and activity across different channels.
- Monitor loan performance and installment information.
- Evaluate branch performance and operational activity.
- Present key business metrics through interactive visualizations.

## Dashboard Structure

The dashboard consists of six main pages:

### 1. Landing Page
An introductory page providing a visual entry point to the dashboard.

### 2. Overview
A high-level summary of the bank's key performance indicators and overall activity.

### 3. Customer Analysis
Exploring customer distribution, demographics, and account characteristics.

### 4. Transaction Analysis
Analyzing transaction types, values, channels, and activity patterns.

### 5. Loan Analysis
Monitoring loan amounts, interest rates, and installment-related metrics.

### 6. Branch Analysis
Comparing branch activity and exploring operational performance.
